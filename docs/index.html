英国投入930万英镑研究儿童社交媒体禁令效果

惠康基金会资助930万英镑开展首个此类大规模研究，通过十个项目追踪英国2027年春季实施16岁以下社交媒体禁令前后的变化，覆盖30多万年轻人。研究将探讨禁令对心理健康、睡眠、体育活动、社交网络和学业表现的影响，并调查风险内容是否转移至其他平台。研究人员称这是“一代一遇”的机会，可大规模研究社交媒体对青少年心理健康的影响。

来龙去脉 / 澳大利亚去年率先实施16岁以下社交媒体禁令，加拿大、希腊和丹麦也在考虑类似措施。英国禁令将禁止儿童使用Instagram、YouTube、TikTok、Snapchat、Facebook和X等平台，并限制直播和游戏平台陌生人联系。支持者担忧依赖社交媒体建立友谊的青少年受影响，批评者指出儿童可能绕过禁令。研究还将关注不同性别、社会阶层和性取向群体的差异，以及家庭如何应对限制。
