国台办与进出口银行签“十五五”金融合作协议

新闻速览

国务院台办与中国进出口银行23日在北京签署《“十五五”时期促进两岸融合发展金融合作协议》，将在台商台企扎根大陆、涉台园区建设、两岸企业贸易往来、台企参与共建“一带一路”等方面提供融资支持。国台办主任宋涛称这是解决台商融资问题的具体举措；台企联会长李政宏称协议是“及时雨”。有台商透露今年初曾获5000万元融资。

背景与影响
