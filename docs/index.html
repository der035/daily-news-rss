发生了什么？

11月18日，复旦安联金融保险研究中心发布《行稳致远：中国企业出海风险识别与管理研究报告》，指出中国企业出海风险已从汇率波动、市场需求为主的经营性风险，演变为政治审查、地缘冲突、属地合规、知识产权、监管审评与供应链脆弱性交织的复杂风险体系，归纳为政治、地缘、法律与责任、属地经营、并购整合、宏观经济与市场波动、融资与流动性七类。报告认为保险不能兜底一切，需与内控、政策性工具协同锁定尾部损失。
