新版婴幼儿辅食生产审查细则发布

新闻速览

国家市场监督管理总局11月23日公布《婴幼儿辅助食品生产许可审查细则（2026版）》，自发布之日起施行。细则明确不得用同一配方生产不同品牌婴幼儿辅助食品，仅有包装场地、工序、设备而无完整生产工艺条件的不予生产许可。细则要求对主要原辅料供应商现场质量安全审核，严禁使用从散户采购的畜禽类原料，并规定不应使用香辛料、蜂蜜、辐照处理过的原辅料。

背景与影响

细则适用于6~36月龄较大婴儿和幼儿食用的谷类辅助食品、罐装辅助食品和辅食营养补充品，不适用于婴幼儿配方食品。已获证但不符合要求的企业应在2027年6月30日前完成整改，经现场核查通过后方可生产。与原2017版细则不一致的，以新细则为准。
